# موقع مجتمع Xbrhi 🎮

## نبذة عن الموقع
موقع مخصص لمجتمع Xbrhi يوفر معلومات عن الشخصيات والفريق والمكافآت وطلبات الانضمام للفريق.

## المميزات ✨

- **تصميم عصري**: واجهة مستخدم حديثة مع دعم كامل للعربية (RTL)
- **صفحة رئيسية جذابة**: عرض احترافي للمحتوى
- **أرشيف الشخصيات**: معلومات عن شخصيات المجتمع
- **قسم المجتمع**: روابط مباشرة للديسكورد والكيك
- **مكافآت الداعمين**: عرض المزايا الحصرية
- **ألعاب تفاعلية**: قسم الألعاب والمسابقات
- **نموذج الطلبات**: للانضمام إلى فريق العمل
- **فريق العمل**: عرض أعضاء الفريق

## الملفات 📁

- `index.html` - الصفحة الرئيسية
- `style.css` - ملف التنسيقات والأنماط
- `README.md` - هذا الملف

## كيفية الاستخدام 🚀

1. استنسخ المستودع
2. افتح ملف `index.html` في متصفحك
3. أضف صورك والشعارات في المجلد الرئيسي:
   - `logo.png` - شعار المجتمع
   - `brhi-character.jpg` - صورة الشخصية
